# 4차시 과제 발표 대본

예상 시간: 약 4분

## 1. 프로젝트 소개

안녕하세요. 제 프로젝트는 **미국 경제지표 발표 전후에 주식시장이 어떻게 움직였는지 검증할 수 있는 데이터 파이프라인**입니다.

장기적으로는 이 결과를 자동매매 전략 연구에 활용하고 싶습니다. 다만 지금 바로 주문 기능을 만드는 것이 아니라, 먼저 판단에 사용할 데이터를 안정적으로 수집하고 저장하는 것이 이번 과제의 목표입니다.

## 2. 사용하는 데이터

데이터는 목적에 따라 나눴습니다.

이번 과제의 Kafka 데이터는 2026년 8월 12일 CPI 발표 시각과 같은 구간의 NVDA 실제 IEX 거래입니다. 발표 전 60분부터 정규장 개장 후 4분까지 1,576건을 가져왔습니다. 무료 IEX 데이터이기 때문에 전체 시장을 대표하는 확정 신호가 아니라, 발표 당일 실시간 파이프라인을 재현하는 용도로 사용합니다.

같은 CPI 발표 전후의 Alpaca historical SIP 1분봉도 별도로 수집했습니다. SIP 데이터는 더 넓은 시장 범위를 보여주므로 IEX 결과를 사후 분석하고 coverage를 확인하는 데 사용합니다.

경제지표는 BLS의 공식 CPI 발표 시각과 ALFRED의 당시 CPI·근원 CPI 값을 수집했습니다. 현재 CPI 발표 12회와 네 종목의 SIP 1분봉 5,320건을 저장했고, 발표 전후 5분, 30분, 60분의 가격, 거래량과 변동성을 계산했습니다.

## 3. 전체 데이터 흐름

전체 흐름은 이렇습니다.

실시간 거래 데이터가 들어오면 수집 프로그램이 Kafka에 전달합니다. Kafka는 수집과 처리를 분리하고, 처리 프로그램이 잠시 중단돼도 데이터를 다시 읽을 수 있게 해줍니다.

Spark는 개별 거래를 종목별 1분봉으로 묶고, 중복과 늦게 도착한 데이터를 처리합니다. 최종 결과는 PostgreSQL에 저장해서 SQL로 조회할 수 있게 합니다.

Airflow는 실시간 경로가 아니라 경제지표와 과거 시장 데이터를 일정에 맞춰 수집하고, 실패한 작업을 재실행하는 배치 작업에 사용할 예정입니다.

즉, 공식 CPI 발표 시각을 기준으로 **IEX raw trade → Kafka → Spark → PostgreSQL** 경로와 **SIP 1분봉 → CPI 반응 분석** 경로를 같은 시간축으로 연결했습니다.

## 4. 현재 구현과 검증 결과

말로만 설계한 것이 아니라 실제 데이터로 단계별 확인도 했습니다.

먼저 지난주에는 미국 정규장에서 Alpaca WebSocket의 실제 IEX 거래 10건을 받아 Kafka에 넣고 다시 읽는 것까지만 확인했습니다.

이번에는 프로젝트 주제와 연결하기 위해 8월 12일 CPI 발표 구간의 NVDA 실제 거래 1,576건을 Kafka에 발행했습니다. Producer와 Consumer, Spark 입력이 모두 1,576건으로 일치했고 validation 오류는 0건이었습니다. 이 가운데 watermark를 통과한 거래 509건이 PostgreSQL의 최종 1분봉 18건에 반영됐고 중복 키는 0건이었습니다.

자동 테스트는 70개가 통과했습니다. Spark에서는 event time, 중복 제거와 watermark를 확인했고, PostgreSQL에서는 같은 데이터를 다시 처리해도 business key 기준으로 중복되지 않도록 했습니다.

요청은 발표 전 60분부터 시작했지만 무료 IEX에서 첫 체결은 발표 20분 전인 12시 10분 UTC에 나타났습니다. 따라서 장전 전체 거래를 다 봤다고 말하지 않고, 더 넓은 SIP 데이터와 구분해서 해석합니다.

## 5. 다음 단계와 피드백 질문

다음 단계는 이 과거 replay와 동일한 구간 계약을 실제 CPI 발표 당일 WebSocket 수집에 적용하는 것입니다. 이후 Airflow로 공식 발표 일정, ALFRED 값과 SIP 사후 검증을 자동 실행할 계획입니다.

멘토님께는 두 가지를 여쭙고 싶습니다. 첫째, 현재 규모에서도 Spark를 학습 목적으로 유지하는 것이 적절한지, 아니면 처리량 비교 결과에 따라 Python 처리기와 비교하는 것이 좋은지 궁금합니다. 둘째, 원본 거래를 Kafka에 24시간 보관하는 현재 정책이 과제 범위에 적절한지도 피드백받고 싶습니다.
